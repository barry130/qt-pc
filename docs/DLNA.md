# 普通 DLNA 投屏

播放条的投屏按钮可把当前音乐发送到同一局域网中的 DLNA MediaRenderer（电视、音箱等）。接收设备使用自己的播放器，轻听继续管理队列、歌词与播放进度。

## 使用

1. 让电脑与接收设备连接同一局域网，并启用设备的 DLNA 接收功能。
2. 点击播放条的投屏按钮，刷新设备列表后选择设备。连接时保留当前曲目与播放/暂停状态。
3. 播放条可继续控制播放、切歌；拖动进度、暂停和音量依接收设备公布的能力开放。投屏期间不支持倍速。
4. 在投屏面板选择断开，或选择切回本机继续播放。

本地文件和需要请求头的在线音频由本机临时 HTTP 服务提供给接收设备。请允许应用通过系统防火墙访问专用网络；访客 Wi-Fi、客户端隔离或跨子网可能阻止发现与播放。媒体地址带随机会话令牌，断开后失效。

## 行为与限制

- 队列、系统媒体键与播放状态仍由轻听管理；正常播完会推进下一首。暂停、手动停止、网络失败和过期设备回包不会被当作播完。
- 投屏时音频在接收设备上解码，本机均衡器、增益与淡入淡出不作用于远端输出。
- 音频格式支持取决于设备；轻听不会把不支持的格式自动转码。部分设备没有暂停、定位或音量服务，相应控件会禁用。
- 设备发现和媒体传输只使用本机原生投屏模块，音源脚本不能借此访问局域网地址。
- 已提供模拟设备与协议回归测试；真实电视/音箱及 macOS/Linux 实机兼容性仍需分别验证。

开发接口、测试命令与模块边界见 [DLNA_IMPLEMENTATION.md](DLNA_IMPLEMENTATION.md)。
