# 轻听 3.1.0 更新说明

鉴于近期不少用户把反馈与需求当成询问软件怎么使用，为了提高大家自己多点、多摸索页面的能力，本版本起反馈与需求功能改为只能通过 [CNB](https://cnb.cool/canace/qt-pc) 或 [GitHub](https://github.com/barry130/qt-pc)（需单独注册账号）提 Issue 解决。

## 新增

- **升降调**：播放条上即调即用，半音级升降，设置页同步并记忆。
- **账号每日推荐与私人 FM**：登录账号后接入对应平台的每日推荐与 FM，推荐源可切换，退出时恢复原队列。

## 优化

- **歌单封面换/清**：云端上传成功才落地生效，失败明确提示原因、不再半更新；按钮带「上传中 / 恢复中」状态。
- **更新说明与弹层**：更新说明按 Markdown 富文本排版；弹层限制在窗口内并自动滚动。
- **清理更聪明**：清缓存时保留正在播放与预加载的媒体文件，不打断播放。

## 修复

- **DLNA 连播**：修复部分电视和音箱播放结束后停在当前歌曲的问题，兼容结束时进度归零或清空媒体地址，并避免手动暂停、定位或停止时误切歌。
- 网页登录前清理共享 Cookie，账号之间不再串扰。
- 音源包更新后偶发取链失败：支持长包头探测，更新后旧取链缓存自动失效。
- 拖动歌单 / 列表时被系统拖放行为打断。
- 录音版 / Live 标识不再丢失。

---

**升级提示**：版本 3.0.9 → 3.1.0。数据、歌单与已登录账号自动沿用，无需重新配置。
