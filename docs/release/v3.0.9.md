# 轻听 3.0.9 更新说明

从 1.1.3 到 3.0.9 是一次跨大版本升级。原有收藏、歌单、设置与听歌记录全部保留，无需重新配置。

## 新增

- **音源账号**：网页登录，登录态后台保活，过期自动刷新。
- **账号歌单同步**：与本地收藏对比差集，勾选即一键收藏。
- **私人 FM**：心动 / 常听 / 探索三档口味，退出时恢复原队列与原播放模式。
- **四种播放页样式**，播放条标注当前实际音源。
- **本地曲库**：标签编辑、五星评分、智能歌单、曲库监听、整理与库体检、BPM。
- **听歌上报**：Last.fm / ListenBrainz 二选一，失败自动退避重试。
- **播客**：RSS 订阅、离线转写与翻译，字幕可同步到桌面歌词窗。
- **AI 助手**：本机小模型或服务端模型，供应商可自建，支持测试连接。
- **中英双语界面**，数字、日期、播放量随语言本地化。
- **命令面板、快捷键、读屏播报、DLNA 投送**。
- **歌单改名与封面**、歌曲与歌单分享卡。
- 更新说明支持富文本；首次启动免责声明改由后台下发。

## 优化

- 迷你窗与歌词窗隐藏即降档，实测待机单核占用由约 7% 降到 1～3%。
- 无缝播放预热提前到当前曲目加载完成，失败自动换目标重试。
- 列表统一一次性加载，去掉滑动加载；详情页、空态、骨架屏、弹窗风格统一。
- 设置页文案精简，AI 配置改为「先选引擎，再配模型」。
- 听歌报告 30 天视图改为横向月历，切换区间不再白屏。
- 收藏重复判定放宽；歌单多版本弹窗保持打开直到确认。

## 修复

- 5.1 / 7.1 多声道 FLAC 无声、音量偏低、歌词整体错位。
- 浅色主题下当前歌词行几乎看不见（按底色自动校正对比度）。
- 换源后桌面歌词窗仍按旧音源取词。
- 拖动进度条后播放位置闪回。
- 同步来的 B 站歌单点开为空；酷狗分享歌单只显示 10 首。
- 托盘「迷你模式」勾选状态与实际窗口不符。
- 网页登录关窗后一直显示「登录中」，要等三分钟超时。
- AI 会话旧回复覆盖新提问、分页缓存串数据、嵌套弹窗丢失焦点。
- 反馈信息把 Windows 11 识别成 Windows 10。

---

**升级提示**：版本 1.1.3 → 3.0.9。音源能力仍由第三方音源包提供，应用不内置也不分发；升级后若某平台不可用，请到「设置 → 音源包」安装或更新对应包。数据与已登录账号自动沿用。
