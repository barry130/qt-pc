QuietMusic · Release Notes

轻听 3.0.9 更新说明

从 1.1.3 到 3.0.9 的全部变化 · 面向使用者的版本说明

版本 3.0.9 versionCode 309 上一版 1.1.3（113） 覆盖 2026-10-18 ～ 2026-11-08 桌面端 Windows / Linux / macOS

这是一次跨越大版本的整体更新：音源账号、私人 FM、本地曲库管理、播客与字幕、AI 助手、中英双语界面、DLNA 投送 这批能力都在这一版里补齐；播放器、列表、设置界面做了重构，待机占用明显下降；同时集中修掉了一批长期困扰使用的 播放与歌词问题。原有的收藏、歌单、设置和听歌记录都会自动保留。

01 音源与账号

这一版把「换源」从一个开关做成了完整的一套账号体系。

音源账号

  • 新增 音源账号页：登录在内嵌网页里完成，不用跳出应用；登录态在后台保活，B 站 Cookie 到期会自动刷新。
  • 新增 账号歌单同步：登录后自动对比平台歌单与本机收藏，差集可勾选一键收藏；同步结果是全量清单，带「已收藏」标记，也能就地取消收藏。
  • 新增 同步前的登录态前置检查，失败时弹窗里直接给「一键开启并重试」。
  • 新增 换过音源包或音源包已下架后残留的账号卡，会明确标出「音源包已卸载」，不再显示一个看不出是什么的原始 id。
  • 修复 关掉网页登录窗口后一直卡在「登录中」、要等三分钟超时的情况，现在立即复位。
  • 改进 网页登录失败时，提示会列出抓到的 Cookie 名称（只有名字，没有值），便于判断是「没抓到」还是「被官方拒绝」。

音源解析

  • 修复 酷狗分享短码歌单只显示 10 首：改为先用短链换取公开歌单 id 再走全量通道，实测 175 / 549 首这类歌单都能完整读取。
  • 修复 同步来的 B 站收藏歌单点开为空。
  • 改进 B 站收藏歌单按分 P 章节展开；多 P 视频按首 P 的真实时长折算码率，挑轨更准。
  • 改进 上游限流不再被当成「这首没有」：自动按建议间隔重试并换线，长歌单的成功率明显上升。
  • 改进 码率不再是硬性否定条件——某个档位取不到时优先保证能播，而不是直接判定这首歌不可用。
  • 新增 聚合搜索：一次查询合并多个音源的结果，每条结果标出来源平台；播放条也显示当前实际音源徽标。

02 播放体验

播放器在这一版被重做过一遍，外观、音质和稳定性都有变化。

播放界面

  • 新增 四种播放页样式，各有独立背景，可按喜好切换；播放中始终标注真正的取流来源。
  • 新增 歌词逐字/逐行同步渲染，桌面歌词窗与主窗口共用同一份时间轴。
  • 新增 歌词字号可调。
  • 新增 播放队列面板高亮当前行（竖条 + 跳动条 + 主色歌名），滚动时也能一眼找到正在放的那首。
  • 新增 播放页右键「分享歌曲」：生成分享图，右下角内嵌下载页二维码。

音质与播放稳定性

  • 修复 5.1 / 7.1 多声道 FLAC 没有声音：中置与环绕声道被直接丢掉，电平低了 6～10 dB，时长也按错误声道数折算，于是歌词整段错位。现在按 ITU-R BS.775 系数降混到立体声，正常出音、正常对轴。
  • 新增 ReplayGain 音量均衡，可按单曲或按专辑两种口径。
  • 改进 无缝播放的预热提前到「当前曲目加载完成」那一刻，失败会自动换目标重试；拖动进度条、临时调速不再白白作废已经取好的下一首。
  • 新增 本地文件优先播放：同一首歌本机有文件时优先用本地，不占带宽。
  • 修复 拖动进度条后位置「闪回」到上一处再跳回来。

私人 FM

  • 新增 私人 FM 全链路：心动 / 常听 / 探索三档口味，每轮 12 首，自动补歌，关掉页面也会继续补。
  • 改进 进 FM 前会把你正在听的队列整份存下（含进度与暂停状态），退出时原样恢复，播放模式也还回原来的。
  • 改进 队列被手动换走时 FM 会自动让位，不会往别人的队列里继续追加。

03 本地曲库

本机音乐从「能放」变成「能管」。

  • 新增 标签编辑：改标题、歌手、专辑、年份等标签；写入前自动做快照，可以整单恢复。
  • 新增 5 星评分，列表页直接显示星级列。
  • 新增 智能歌单：规则存在库里、曲目实时计算，支持按 BPM 等条件筛选。
  • 新增 本地曲库监听：文件新增、改名、删除后自动增量入库，不用手动重扫。
  • 新增 音乐整理与库体检：缺失文件、沉睡 30 天、超长（10 分钟以上）分组列出，可逐条忽略与恢复；移动文件前先落撤销记录，可以整体回退。
  • 新增 BPM 识别（读文件标签，20～400 之外视为未知）。
  • 新增 听歌上报：Last.fm 与 ListenBrainz 二选一，同一时刻只报一家；网络抖动会退避重试。
  • 新增 诊断包导出：一键打包版本、平台、库体检、表统计、打码后的设置与日志尾部，反馈问题时有据可查。
  • 新增 便携模式：程序目录放一个 portable.txt（或设置环境变量），数据就跟着程序走，不进系统用户目录。
  • 新增 系统级唤起重播：quietmusic://play 链接可直接播放已在本机的文件。
  • 新增 歌单可改名、可换封面（选图 / 预览 / 清除），封面会复制进数据目录并同步到云端；云端失败不影响本地，界面会说明当前是「已同步 / 离线 / 失败」以及后端给出的原因。
  • 新增 歌单分享卡：前 4 首封面 2×2 拼图，整卡预览不裁切。
  • 改进 收藏时的重复判定放宽，同名不同版本不再被粗暴判成「已存在」；歌单多版本选择会一直保持打开，直到你确认。
  • 改进 听歌报告：30 天改为横向月历（格子大小与一年视图不再打架），切换区间时保留旧数据，不再整块白屏。

04 播客与字幕

  • 新增 播客订阅：RSS 添加、单集列表、按订阅更新。
  • 新增 字幕识别：可走云端转写，也可用本机 whisper.cpp 离线跑；短音频自动识别，长音频分段。
  • 新增 离线翻译（Argos）：无需联网即可把字幕译成中文。
  • 新增 字幕同步到桌面歌词窗，边听边看。
  • 改进 没有时间轴的字幕不再反复刷新播放状态，长播客的界面更省电。

05 AI 助手

  • 新增 两条路线：本机跑的小模型，或走服务端模型；可在设置里切换。
  • 新增 本地模型可自行添加与编辑供应商（地址、模型、密钥、协议），并按组展示。
  • 新增 「测试连接」：用当前填写的配置真发一句话试一试，只试不存；结果就地显示，改任一字段即清空旧结论。
  • 新增 会话历史，以及「AI 助手」独立入口。
  • 改进 设置页改成两步一页：第 1 步先选引擎，第 2 步才出现模型配置，不再把有依赖关系的两件事并排放。
  • 修复 旧回复覆盖新提问（串台）、分页缓存串数据、嵌套弹窗丢失键盘焦点。

06 界面与交互

  • 新增 中英双语界面：侧边栏、窗口按钮、设置全部分节、播放队列等完成词条化；播放量「万/亿」与「K/M/B」、日期与时长按语言本地化。缺词条时回退中文。
  • 新增 命令面板：一个入口搜页面、搜设置、直接「喜欢/取消喜欢当前曲目」。
  • 新增 键盘与读屏可达：空格播放/暂停、方向键前后 10 秒、进度条可键盘操作、切歌有读屏播报、切页后焦点回到内容区。
  • 新增 页面空白处右键不再弹系统原生菜单（划选文字仍然放行）。
  • 改进 标题栏右侧入口重排为 头像 → 通知 → 设置 → 皮肤 → 窗口控制；「外观」提升为一级页面，原设置内地址自动跳转。
  • 改进 列表统一改为一次性加载，去掉了滑动加载与底部「已经到底了」；同时设了分页护栏，超长歌单也不会把界面拖死。
  • 改进 详情页版式统一（左封面 176px、右侧信息），加载态统一由骨架屏接管；空态、按钮、弹窗、输入框收敛到同一套组件，Esc 关闭与焦点陷阱行为一致。
  • 改进 设置页文案精简 93 处，13 个分节拆开按需加载，音源包教程入口提到页顶。
  • 新增 首页通告栏与消息中心：公告类型、链接打开方式与后台口径统一；「仅首次登录」的公告改为按条记录，关掉一条不会连带错过下一条。
  • 新增 更新说明支持富文本：后台按 HTML 下发的说明会正常渲染标题、加粗、列表和链接，脚本类标签一律剔除；说明区限高可滚动，不会把「立即更新」顶出屏幕。
  • 新增 首次启动的免责声明改由后台下发：文案、读秒、条款版本都能在后台改，不用发版；改过版本会重新征询，老用户已同意的不会被重复打扰。
  • 新增 每日推荐页；更换头像后，各页面即时同步。
  • 新增 DLNA 投送控制：在播放控制里查看并选择局域网内的渲染设备。

07 性能与占用

这一段是「为什么这一版更轻」。

  • 改进 迷你窗、桌面歌词窗改为独立入口，不再各自加载一份完整主界面。
  • 改进 迷你窗隐藏即销毁、需要时再建（约 0.3 秒），不再常驻一个渲染进程。
  • 改进 三处 60fps 空转收敛：播放位置按 100ms 步进、桌面歌词 30fps 且暂停即跳过、播放条频谱 30fps 且零信号停机。
  • 改进 窗口隐藏时暂停全部动画与过渡，并把 WebView 内存档位降到低位，恢复可见时回升。
  • 改进 实测待机单核占用由约 7% 降到 1～3%。
  • 改进 批量检查收藏时只准备一次候选并让出主线程；无时间轴字幕不再持续触发播放状态更新。

08 修复清单

按影响面排列，前几条是这一版最值得升级的理由。

  • 多声道（5.1 / 7.1）FLAC 无声、音量偏低、歌词整体错位。
  • 浅色主题下正在唱的那一行几乎看不见（现在按底色自动校正对比度，最低 5:1）。
  • 换源之后桌面歌词窗仍按旧音源取词，歌词与正在播放的版本对不上。
  • 拖动进度条后播放位置闪回。
  • 同步来的 B 站歌单点开为空；酷狗分享歌单只显示 10 首。
  • 托盘菜单「迷你模式」的勾选状态与实际窗口不符。
  • 网页登录关闭窗口后一直显示「登录中」，要等三分钟超时。
  • AI 会话里旧回复覆盖新请求；分页缓存串数据；弹窗嵌套后丢失焦点。
  • 歌单版本选择被自动关掉、重复匹配过严导致少收藏。
  • 反馈信息里的版本识别把 Windows 11 显示成 Windows 10。
  • macOS 构建的两处编译期死代码，CI 镜像同步迁移到 macos-15。

09 升级须知

  • 版本号：1.1.3 → 3.0.9（versionCode 113 → 309），与移动端 3.x 采用同一套编号口径。
  • 数据保留：收藏、歌单、设置、听歌记录、已登录的账号都会沿用，升级不需要重新配置。
  • 音源能力仍由第三方音源包提供，应用不内置也不分发音源内容；升级后若某个平台用不了，请先在「设置 → 音源包」里安装或更新对应的包。
  • 首次启动会由后台下发免责声明，按提示确认即可；此前已同意过的不会重复弹。
  • Windows：安装包旁边的 .sig 是应用内自动更新的验签文件，手动安装可以忽略它。
  • macOS：包未签名也未公证，首次打开会提示「已损坏」。在访达里右键点应用 →「打开」，再点一次「打开」；或在终端执行 xattr -dr com.apple.quarantine /Applications/QuietMusic.app。
  • Linux：deb 需要 glibc 2.32 及以上（Ubuntu 22.04 / Debian 12 均可），发行版较老请用 AppImage；Linux 不支持应用内自动更新。
