# 播客字幕与中文翻译

播放一集播客后，点击底部播放条的封面打开播放页，即可进入字幕阅读区。播客使用独立的字幕数据，不再向歌曲音源搜索同名歌词。

## 使用方法

1. 云端模式首次进入会查找 RSS 中的 `podcast:transcript`。本地模式不自动请求节目字幕；仍可主动点击「获取字幕」。节目没有提供字幕时，可导入或生成。
2. 「导入／替换字幕」支持 UTF-8 的 SRT、WebVTT、JSON 和 TXT。JSON 支持 `segments` 或 `cues` 数组，字段为 `start/end/text` 或 `startTime/endTime/body`，时间单位是秒。TXT 只作为文字稿展示，不提供跳转。
3. 「翻译中文」与语音转写独立。在字幕设置的「中文翻译方式」可选择在线 AI 或轻量本地英译中。在线使用「设置 → AI」当前启用的供应商与聊天模型；本地使用下面的 Argos 专用模型。进度显示翻译引擎、已完成句数／段数和当前批次等待秒数。短字幕最多 12 句、约 1.4 KB 一批；长文字稿通常一段一批，完成即展示和保存。每批最多等 60 秒；失败或取消后保留已完成部分，再次点击只翻译缺失内容。
4. 显示方式可选「双语／原文／中文」。带时间轴的字幕支持点句跳转、上一句、下一句、重听本句。默认自动定位当前行；手动滚动暂缓跟随，停止翻阅 4 秒后恢复，也可点「回到当前播放」立即恢复。点句跳转和拖动播放进度会恢复跟随；新识别结果或译文到达后，按真实行高重新定位。长文字稿每页显示 200 句，播放会自动翻页。
5. 开启桌面歌词后，播客使用本集带时间轴的字幕；新生成的原文、译文实时同步到独立歌词窗口，双行模式显示当前原文与译文。中文原文与译文相同时不重复。主窗口离开播放页也能同步，歌词窗口稍后打开会补读当前字幕，换集与旧任务迟到结果不会串集。没有时间轴的文字稿提示在播放页阅读，不伪造同步行。

## 本地离线识别

打开播客播放页，在字幕区点击齿轮，将「识别方式」切换为「本地离线 · whisper.cpp」。无需配置 AI 供应商或 API Key。

1. Windows x64 可直接在「下载离线模型」选择 tiny（77.7 MB）、base（148.0 MB，默认推荐）、small（487.6 MB），点击「下载并自动配置」。均为支持中英文的多语言模型，较大模型通常更准确，也更慢、更占内存。
2. 首次会自动下载 [b5454 官方 Windows x64 CPU 引擎](https://github.com/ggml-org/whisper.cpp/releases/tag/b5454)（8.9 MB）和所选模型，校验大小与 SHA-256 后解压引擎、保留 DLL 并填写路径。进度显示当前文件的已下载大小与百分比，可以取消、失败重试，关闭设置后继续下载，重开恢复进度；退出应用会中止下载。已完整校验的下载文件可复用，未完成片段不续传。失败或取消不会替换原配置。自动安装引擎使用 CPU，显卡选项禁用。
3. 已有文件仍可点击「选择引擎」「选择模型」。从 [官方发布页](https://github.com/ggml-org/whisper.cpp/releases) 或 [GGML 模型仓库](https://huggingface.co/ggerganov/whisper.cpp/tree/main) 手动下载亦可；Windows 选择 `whisper-cli.exe` 并保留同目录 DLL，Linux/macOS 选择自行编译的 `whisper-cli`。显卡版需手动选择对应引擎、安装驱动。默认使用 4 个 CPU 线程。
4. 保存设置，回到字幕页。「缓存节目音频」会联网下载本集音频；也可以点击「选择本地音频」，选择与当前节目同一版本的 MP3、WAV、M4A、FLAC、OGG、AAC 或 Opus 文件。
5. 引擎、模型和音频准备好后，可断网点击「生成当前五分钟」或「生成整集字幕」。每段完成即保存，取消会终止本次本地识别进程，再次生成只补未完成段。
6. 已生成的内容不满意时可点击「重新生成整集」，或定位到对应时间后点击「生成当前五分钟」并确认重新生成。使用当前模型和语言设置，每个五分钟片段成功后才替换该段原文、清除该段旧译文；失败或取消保留未完成片段的原内容。整集已有内容时显示「整集已生成」，不会再以续传按钮无声跳过。云端重新生成可能再次计费。

本地识别内部使用约 20 秒的窗口，两侧保留 1 秒音频上下文，过短尾段并入前窗，仍按五分钟一批保存。每个窗口单独判断语言，不携带前窗文字上下文，减少中英切换时误判和重复循环。已明确知道节目全程使用一种语言时可填写 `en` 或 `zh`；中英混合节目建议保留自动识别。若仍连续重复较长句子，本批会提示识别异常，不把重复循环保存为成功结果，可尝试 small 模型。

whisper.cpp 偶尔会在句子边界返回多条起止时间相同的重复文字；这些片段会去重，保留相邻有效字幕，不再导致整段识别失败。独有文字若没有有效时长仍会提示重试，不会凭空生成时间轴。短窗口最后一句最多允许 2 秒尾部容差，结束时间裁剪到实际音频长度；开始时间仍必须处于真实音频内。其他越界或格式错误继续报错，并显示具体失败的时间范围。

本地识别不会上传音频，也不会失败后改用云端。引擎和模型只在主动点击下载按钮后联网获取；自动或手动开始边播边识别时，本集尚未缓存则先下载节目音频，完成后接着识别。普通五分钟/整集生成仍使用已准备的本地音频。缺失的已选本地文件、模型错误或引擎失败会直接提示。已开始识别的节目不能切换为另一份本地音频，以免续传时混用时间轴；请保持原音频路径和内容不变。

自动下载跟随「设置 → 网络」的代理；连接官方源失败或 45 秒无数据会提示重试。引擎和模型保存在应用数据目录的 `offline-whisper` 中，不随音频缓存清理；普通 Windows 安装通常位于 `%APPDATA%/QuietMusic/offline-whisper`，便携模式随应用数据目录。文件不随安装包内置，安装时使用固定官方版本和校验值。

本地文件目前用于字幕识别；播放器的播放来源仍为原节目。Whisper 只生成原语言字幕；翻译引擎需单独选择和准备。

## 轻量本地翻译

在「播客字幕设置 → 中文翻译方式」选择「本地 · 轻量英译中（Argos）」，点击「下载英译中模型」。Windows x64 可直接下载、校验和安装，无需另装 Python、Ollama、LM Studio 或开启本机服务。取消和重试都支持，关闭设置窗口后下载继续，重开可查看进度；退出应用会停止未完成安装。

- 模型为 Argos `translate-en_zh-1_9`，由 OPUS-MT 英译中模型派生，CTranslate2 INT8 CPU 推理。模型压缩包 70,743,021 字节，运行组件和模型合计 117,288,717 字节（约 117 MB）；安装解压及保留下载包会占用更多磁盘空间。
- 固定版本组件：Python 3.11.9 嵌入式运行时、CTranslate2 4.8.5、SentencePiece 0.2.3、NumPy 2.3.5、PyYAML 6.0.3。官方下载和 SHA-256 固定在 `translation.rs`，不会运行 pip 或修改系统 Python。应用目录 `offline-translate` 保存专属运行时，模型许可与各运行组件的许可保留在下载包/安装目录中。
- 翻译时仅启动本地工作进程，不上传字幕、音频，不读取在线 API Key，也不回退云端。每批完成立即保存；取消或 60 秒超时会终止该工作进程并保留已完成译文。
- 专用模型支持**英文 → 中文**，以中文为主的原文直接保留。其他语种需切换在线翻译。它适合快速理解播客内容，专业术语、人名和复杂语境可能不如更大的聊天模型，识别原文中的错误也会影响翻译。长段按句子及 token 上限分段处理，不静默截断。
- 原文和译文相同时，双语模式只显示一行；选择「中文」仍可阅读该内容。
- 可勾选「边播边识别时，自动本地翻译新字幕」。该开关仅在下面的边播边识别任务中生效；普通五分钟/整集生成后仍通过「翻译中文」发起翻译。在线翻译不会自动启动。

模型来源：[Argos 模型索引](https://github.com/argosopentech/argospm-index)，[OPUS-MT](https://github.com/Helsinki-NLP/Opus-MT)。模型包 README 标明原始模型采用 CC-BY 4.0，并署名 Jörg Tiedemann 和 Santhosh Thottingal，论文 *OPUS-MT — Building open translation services for the World*（EAMT 2020）。

## 边播边识别

本地识别模式默认开启「播放播客时自动识别字幕」。准备好引擎和模型后，播放播客即启动，切换节目自动接续，离开播放页也继续；普通音乐与云端模式不会自动转写。可在字幕设置关闭该选项，改用「边播边识别」手动启动。旧本地配置未保存该选项时默认开启，显式关闭后会记住。

新节目无需先手动缓存：开始任务后检查本集音频，未缓存则下载，显示已下载 MB、等待时间，完成后自动识别当前播放位置。它根据已下载音频提前生成字幕，**不是麦克风流式识别，也不保证零等待**。

缓存期间可以「停止本集识别」；换集会取消旧任务，旧任务收尾后开始新节目，不在缓存结束后继续识别旧节目。手动停止或失败后，本集不会因播放进度、暂停恢复而循环重启，可再点「边播边识别」重试；下一集仍按自动设置启动。关闭自动设置会取消当前自动任务。已选择的本地音频若丢失会提示恢复原文件，不自动改用可能不同版本的网络音频。

每个请求识别约 20 秒，成功后立即显示并保存，优先处理当前播放位置至前方约一分钟。拖动进度后，正在运行的小段完成，再按新位置调度；暂停后等待，不继续启动识别/翻译，恢复播放后继续。已完成内容仍可读取，下次启动跳过已完成的小段。若选择本地自动翻译，识别小段后紧接着翻译附近原文，再处理下一段，减少 CPU 同时争用。翻译组件未就绪或翻译失败时，提示并暂停本次任务的自动翻译，保留原文和已完成译文，继续识别；停止识别后可通过「翻译中文」补译。已有节目或导入字幕时，自动流程直接读取并保留，不再下载音频转写覆盖。

短段单独记录覆盖范围，静音也记录为完成；只有五分钟内所有短段都处理完，才计为完整的一段。选择「继续生成整集」时补齐短段缺口，保留已完成原文和译文。重新生成才会按确认提示替换已有内容。异常时间轴或重复循环的短段会拆成两个约 10 秒窗口重新检测语言，最多重试一次，仍失败则提示并保留原内容。

Ryzen 7 6800H、base 模型、4 线程的已缓存节目实测：普通 20 秒窗口约 2.8–4.0 秒；一个中英交界窗口因识别异常重试耗时约 25.6 秒，尾段约 2.1 秒。提前缓存能吸收部分波动，但首次启动、跳转到未识别位置或较弱电脑仍可能等待。轻量翻译实测三句（含一条中文保留）连同进程启动和加载约 0.78 秒。速度不是所有节目与设备的保证。

## 云端转写

先在「设置 → AI」保存一个支持 OpenAI 兼容音频转写接口的供应商，再打开字幕区右侧的设置按钮，选择供应商与转写模型。只复用已选供应商的地址和密钥，字幕偏好不包含密钥。

- 模型使用下拉框。内置 `gpt-4o-transcribe-diarize`（`diarized_json`）与 `whisper-1`（`verbose_json`），返回格式自动匹配。它们对应当前已适配的同步字幕协议，不代表所有供应商都提供这些模型。
- 选择供应商后读取其真实模型列表，使用该档案的地址和密钥，不依赖 AI 设置中勾选的模型子集。内置模型不存在时直接提示并禁止保存；生成前再次核实，缺失时不下载音频、不发送转写请求。网络或模型列表接口失败会提示「无法核实」，不会误报为模型不存在，可点击「刷新模型列表」。
- 下拉框最后一项为「自定义（不保证可用）」。选择后可填写模型 ID，并选择 `json`、`text`、`verbose_json` 或 `diarized_json`；默认 `json`，不附加时间轴专属参数。自定义模型仍使用 OpenAI 兼容的 `/audio/transcriptions` multipart 接口，不会自动改用聊天接口、强制对齐模型或其他供应商。列表缺失或获取失败会提示，但允许保存和尝试。
- 例如 `Qwen3-ASR-1.7B` 可在「自定义」里填写并选择 JSON；能否识别取决于供应商是否实现相应转写接口。不能仅凭模型名称保证成功。旧配置中手填的非内置模型会迁移为自定义 JSON。
- 返回真实 `segments` 时间轴时仍提供同步字幕。返回 JSON `text`、没有时间的文本片段或纯文本时，保留为可阅读、翻译和双语显示的文字稿，不推算句子时间、不提供逐句跟随、跳转和重听。错误响应或越界时间轴仍会报错，不当作有效正文保存。
- 语言留空自动识别，英文可填 `en`，中文可填 `zh`。
- 「生成当前五分钟」适合先试一小段；「生成整集字幕」从当前播放附近开始，再补齐其余未完成段。

首次生成先缓存整集压缩音频，再按约五分钟切成单声道 16 kHz WAV 发送给供应商。左右声道先混合，避免丢掉分在右声道的嘉宾。云端片段按五分钟边界切分，避免服务只返回文字时重复上下文；本地识别保留两秒上下文重叠，按句子中点分配到所属段。单段约 10 MB，低于 25 MB 请求上限。

音频会发送给所选语音转写服务；翻译只发送字幕文本与少量上下文。费用和模型支持范围取决于供应商。取消会停止客户端后续请求，但已经被服务端接收的请求可能仍产生费用。

## 保存与恢复

- 字幕与译文按节目集 ID 保存在本机 SQLite；每批完成即写入，重新打开应用后仍可读取。
- 失败、取消和换集都保留已完成部分；字幕版本冲突会拒绝覆盖并恢复数据库中的最新版本。
- 无时间轴文字稿也按片段保存并跳过已完成段。即使先生成节目中间、再补前面，也按节目顺序阅读；已有译文保留。某集含无时间轴片段时整集以文字稿方式阅读，避免错误同步。
- 重新生成带时间轴的字幕并替换所有旧无时间轴片段后，会恢复逐句跟随、跳转和重听。替换时检查字幕版本，遇到冲突不会覆盖其他更新。节目自带或手动导入的字幕不通过重生成入口覆盖。
- 取消订阅时，字幕随单集记录一同删除。
- 音频缓存在应用缓存目录的 `podcast-subtitles` 子目录；单集最多 512 MB。下载新节目时清理过期缓存和旧临时文件，通常控制在约 2 GB。字幕本身不依赖缓存音频长期保留。

## 第一版范围与限制

2026-11-07 性能补充：无时间轴文字稿不再订阅播放位置或启动插值计时，恢复同步字幕时立即对齐当前播放。base 识别和轻量英译中的本机分段吞吐、首次缓存限制及复现边界见 [性能检查](performance-2026-11-07.md)。

- 支持外置 whisper.cpp 离线识别与缓存音频的边播边识别。首次等待时间取决于音频准备、模型大小和电脑性能，不适用于直播音频或麦克风。
- 只支持已有播放器能解码、定位的直接音频文件。没有时长时可先生成当前位置；整集生成需要有效时长。
- 暂不自动判断动态广告插入、发布方替换同一 URL 音频带来的时间轴变化；这类节目可能需要重新导入匹配当前版本的字幕。
- 发布方的 HTML/PDF 文字稿不在本版解析范围；支持带时间轴格式和纯文本。
- 本地英译中对以中文为主的文本直接保留；在线翻译不自动检测语种，中文节目可直接选择原文。

## 验证方式

原生测试覆盖 RSS 解析和保存、旧数据库升级、字幕格式与时间轴、WAV 解码和声道混合、分段定位、版本冲突、删除清理、取消竞态，以及本地模拟 HTTP 服务接收 multipart 转写请求。本地识别另覆盖模型检查、毫秒时间轴、无隐式下载、取消/超时后的子进程退出和临时文件清理。下载测试检查哈希、解压目录穿越与 DLL 完整性、取消清理、失败时保留原配置。前端测试覆盖下载进度／取消／重开、自动配置、翻译小批次／等待计时／部分失败、跨集隔离、续传、本地模式不依赖 AI 配置、显式准备音频、字幕跳转和显示模式。浏览器预览使用模拟服务验证播放页、设置保存和 800×520 窗口下 125% 字号布局。

本地端到端验证使用官方 b5454 Windows x64 CPU 引擎、多语言 tiny 模型与上游公开 `jfk.wav` 语音样本，实际生成带时间轴的英文字幕，覆盖中文工作路径与清理。另使用已缓存的约 647 秒中英播客和 base 模型完整验证短窗口识别：三个五分钟批次分别生成 66、70、16 条有效字幕，未再出现重复句循环，识别与清理共 124.52 秒。此计数包含批次间上下文，保存时还会按中点归属去除重叠。真实音频和识别正文仅保留在本机临时测试目录，不加入代码测试夹具；回归测试使用自编文字。显卡加速、其他系统和 small 等更大模型未做实机验证。没有调用真实付费转写供应商，云端兼容性与翻译质量仍需使用已配置服务做短段验证。

2026-11-07 本地翻译及边播边识别回归：52 项前端测试、42 项原生字幕测试通过；TypeScript 和相关 ESLint 通过。显式运行 Argos 官方包安装与真实推理、base 的 20 秒短段识别。实际应用内对上述节目重新生成后保存 149 条有效同步字幕，本地译文 149/149，重复循环消失；验证暂停等待、取消和重新进入读取。轻量模型仅作英译中，不能据此保证其他语种、复杂术语或所有设备上的速度与准确性。
